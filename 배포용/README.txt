울산 고등학교 과목 편성 검색기 — 배포용 폴더
================================================

[폴더 구성]
  index.html        검색기 + 시뮬레이터 본체 (약 730KB)
  편제표/            학교별 편제표 45개 (xlsx 40개, pdf 5개)
  README.txt        이 파일

[Vercel 배포]
  vercel.com 에서 이 "배포용" 폴더를 통째로 드래그하면 끝입니다.
  빌드 설정은 필요 없습니다. 정적 파일만 있는 폴더입니다.

[편제표 파일 교체]
  편제표/ 폴더의 파일을 같은 이름으로 덮어쓰면 됩니다.
  파일 이름은 반드시 "학교명.xlsx" 또는 "학교명.pdf" 형식이어야 하고,
  학교명은 검색기의 학교 이름과 글자 하나까지 같아야 합니다.
    예) 강동고등학교.xlsx, 무룡고등학교.pdf
  index.html 은 고칠 필요가 없습니다.

[편제표를 구글 드라이브 등 외부 링크로 돌리고 싶을 때]
  index.html 을 메모장으로 열어 CURR_LINKS 를 찾은 뒤 이렇게 채웁니다.
    const CURR_LINKS={"강동고등학교":"https://drive.google.com/uc?export=download&id=파일ID"};
  링크가 적힌 학교는 편제표 폴더보다 이 링크를 먼저 사용합니다.

[자료 갱신]
  과목 편성 자료(시뮬레이터 내용)는 index.html 안에 들어 있습니다.
  편제표 정리 엑셀이 바뀌면 index.html 을 새로 만들어야 합니다.
